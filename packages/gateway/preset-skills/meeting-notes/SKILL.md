# 会议纪要

## 何时使用
- 用户分享会议记录、讨论内容或需要整理纪要时

## 步骤
1. 提取议题与参与背景
2. 归纳结论与决策
3. 列出行动项、负责人与截止时间
4. 记录未决问题

## 输出格式
- **会议主题**
- **关键讨论**
- **决策**
- **待办事项**
- **未决问题**
