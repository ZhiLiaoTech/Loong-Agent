# Bug 定位

## 何时使用
- 用户报告异常、报错或行为不符合预期时

## 步骤
1. 收集复现步骤、期望与实际结果
2. 定位相关模块、日志与最近变更
3. 形成根因假设并验证
4. 给出修复方案、影响范围与验证方式

## 输出格式
- **现象**
- **复现条件**
- **根因分析**
- **修复建议**
- **验证步骤**
