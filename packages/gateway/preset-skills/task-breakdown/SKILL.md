# 任务拆解

## 何时使用
- 需要将目标、需求或里程碑拆成可执行工作时

## 步骤
1. 明确最终交付物与截止时间
2. 拆分为可独立推进的子任务
3. 标注优先级、依赖与负责人（如已知）
4. 标出风险与阻塞项

## 输出格式
- **目标**
- **任务列表**（含优先级）
- **依赖关系**
- **风险与待确认项**
