# 产品需求文档

## 何时使用
- 需要整理新功能、改版或需求澄清时

## 步骤
1. 明确用户场景与问题
2. 定义目标、范围与非目标
3. 写出用户故事与验收标准
4. 标注依赖、风险与开放问题

## 输出格式
- **背景与目标**
- **用户故事**
- **功能范围**
- **验收标准**
- **开放问题**
