# 抖音短视频脚本指南

## 脚本结构（黄金 3 秒法则）

### 开头（0-3 秒）— 钩子
必须在前 3 秒抓住用户，否则就被划走。

**高效钩子类型：**
1. **反常识开场**：「你以为 XX 是这样？其实完全相反」
2. **痛点共鸣**：「是不是每次 XX 都很崩溃？」
3. **视觉冲击**：直接展示最惊艳的结果
4. **数字冲击**：「只花了 50 块，效果比 5000 的还好」

### 中间（3-45 秒）— 内容主体
- 信息密度要高，不废话
- 每 5-10 秒一个信息点或转折
- 画面切换保持节奏感

### 结尾（最后 3-5 秒）— CTA
- 「关注我，下期教你 XX」
- 「双击❤️收藏，以后用得上」
- 「评论区告诉我你想看什么」

## 标题规范
- 8-15 字，简短有力
- 开头用关键词（搜索优化）
- 可以用 # 话题标签嵌入标题

## 热门内容形式
- 教程类：「3 步教你 XX」
- 合集类：「XX 合集｜第 N 期」
- 对比类：「XX vs XX，哪个更好？」
- 变装/变化类：前后对比
