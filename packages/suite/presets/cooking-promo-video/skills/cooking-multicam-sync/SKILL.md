# 多机位同步

按“硬件时间码 → 机器事件 → 音频互相关 → 人工偏移”的顺序选择同步方法，输出 `analysis/sync-map.json`。所有 offset 使用毫秒，相对参考机位表示。置信度低于 0.70 时停止自动流程并请求人工确认；不得静默采用低置信度结果。

普通网络摄像头既无时间码又无音轨时，仅在操作方明确确认各路录像大致同时开始后，允许使用 `--allow-aligned-start` 将全部 offset 设为 0。输出方法必须为 `aligned_start`、置信度为低值，后续成片必须经过人工审核。
