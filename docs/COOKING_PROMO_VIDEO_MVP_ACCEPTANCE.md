# 自动炒菜机宣传视频 Suite：MVP 阶段验收报告

更新日期：2026-09-05

## 结论

当前版本达到“本地目录投递、2～4 路普通网络摄像头录像、无云端模型时生成待人工确认草稿”的技术演示条件。由于客户真实样本、品牌资产和机器事件协议尚未提供，本报告结论为**工程预验收通过，客户效果验收待完成**。

## 已验证范围

- 指定 inbox 目录扫描、稳定文件判断、`_READY` 标记、幂等消费和来源保留。
- 2、3、4 路 H.264 视频接入；允许某一路无音轨并生成静音替代轨。
- ffprobe 校验、代理、联系表、动态分析、低置信度对齐降级和人工审核阻断。
- 无机器事件、无云端视觉模型时的本地启发式候选生成。
- 清晰度、曝光、黑屏、抖动、连续性、遮挡、重复机位和 9:16 裁切评分。
- 15 秒/30 秒竖版、30 秒横版和 15 秒/30 秒方形 Remotion Composition，以及 FFmpeg 确定性渲染后备链。
- 字幕、Logo 安全区、卖点覆盖、禁用词和证据约束检查。
- H.264/AAC、尺寸、时长、黑屏、冻结、过曝、峰值和静音质量门禁。
- 取消、超时、临时文件清理、断点恢复、跨作业和跨租户目录隔离。
- Studio 审核工作台：同步确认、事件浏览、成片预览、时间线换机位/微调/删除、字幕修改与再次渲染。
- EDL 乐观修订号、审核记录、驳回/返修原因必填，以及批准当前修订后才允许渲染。
- Gateway 进程内作业队列、1-8 路可配置并发上限、同作业去重、排队/运行取消和 SSE/WebSocket 阶段进度事件。
- 视觉/文案模型逐次调用指标落盘，以及调用量、估算费用、平均/P95 耗时、失败分类和流水线耗时聚合查询。
- 人工 EDL 修改和审核结果的隐私化计数采集，以及换机位率、返修原因和质检失败模式聚合接口。
- 黄金样本事件、候选片段、最佳机位和禁用画面标注规范，以及 Schema、跨字段校验器、复核流程和示例文件。
- 食物吸引力、动作明显度、产品露出和构图模型评分协议，以及未授权/不可用情况下的确定性后备评分。
- 对象存储限时 PUT 直传、可恢复分片会话、逐片存储端校验和最终对象完整性门禁。
- 对象存储租户/用户/角色授权、跨租户存在性隐藏、HTTPS 限时下载签名和无敏感载荷审计。
- 原素材、代理、帧和成片独立保留策略，以及默认 dry-run、运行中作业/法律保留保护和删除前后审计。
- Gateway API 与 media/model/render 三类 Worker 的阶段边界、角色校验、预期状态校验和独立执行入口。
- 固定 Node digest、Debian snapshot、FFmpeg、Chromium、中英文字体、pnpm 与 Remotion 依赖的非 root Worker 镜像定义及构建时版本检查。
- 持久阶段队列、角色消费、租约续期与崩溃接管、指数退避、死信重放及投递/结果幂等。

## 未通过或尚不可验收

1. 没有客户真实样本，无法计算事件召回率、镜头可用率和人工换镜率。
2. 没有机器事件协议，尚未实现机器开始时间同步。
3. 云端关键帧许可未确认；适配器、预算、超时和失败边界已实现，但尚未用客户账号执行真实模型调用。
4. 没有品牌 Logo、字体和许可音乐，只验证了可配置能力和默认主题。
5. 本地启发式事件置信度固定为低值，任何成片都必须人工审核。
6. 对象存储分片、租户授权、签名下载和审计协议已完成；具体 OSS/S3 适配器与不可变审计汇聚仍需随生产账号配置，生产队列尚未完成。
7. Linux Worker 镜像版本已冻结并加入构建时检查；当前电脑没有 Docker，首次发布仍需在 CI/构建机完成真实镜像构建与 Chromium 渲染验证。
8. 全仓桌面发行包构建需要 Rust/Cargo；当前电脑未安装 Cargo，因此 Tauri 壳打包未纳入本次通过结论。
9. Studio 试点入口仍使用进程内队列；生产 Worker 所需的持久队列、租约接管、自动重试和死信原语已完成，后续部署需将 Gateway 入队与 Worker 消费切换到该实现。
10. 当前费用是按部署配置估算；真实 Token 与账单费用需在接入客户模型供应商后由客户端回传并校准。
11. 人工反馈分析能力已上线，但当前只有合成测试数据；换机位率和失败模式不能作为客户业务结论。

## 客户资料到位后的验收动作

- 至少选取 20 组授权素材，完成事件和最佳机位黄金标注。
- 统计事件召回率、可用镜头率、生成耗时、失败率和人工修改率。
- 用客户品牌资产生成 15 秒与 30 秒样片，完成宣传合规和版权复核。
- 对机器事件时间与各摄像机时间做漂移、断流和重连测试。
- 根据试点结果冻结验收阈值，并决定是否允许云端视觉模型。
